# Конвертер валют

Одностраничный сайт для перевода суммы из одной валюты в другую.

## Возможности
- Валюты: USD, EUR, KGS, RUB, KZT, CNY
- Конвертация в любую сторону
- Курс за 1 единицу и дата его обновления
- Результат для 100 USD в KGS показывается сразу при открытии

## Как запустить
1. Распакуйте проект.
2. Откройте `index.html` в браузере.
3. Нужен интернет. Установка, регистрация и API-ключ не нужны.

## Как пользоваться
Введите сумму, выберите валюты «Из» и «В», нажмите «Конвертировать».

## Технологии
HTML, CSS, JavaScript без библиотек и фреймворков.

## Файлы
| Файл | За что отвечает |
|---|---|
| `index.html` | Структура: поле суммы, два списка валют, кнопка, результат |
| `style.css` | Внешний вид: светло-зелёный фон, карточка с тенью |
| `script.js` | Получение курса и расчёт |

## API: ExchangeRate-API (открытый доступ)

`https://open.er-api.com/v6/latest/USD` (вместо `USD` подставляется валюта «Из»)

| Поле ответа | Значение |
|---|---|
| `result` | `"success"`, если всё в порядке |
| `rates` | Курсы всех валют относительно выбранной |
| `time_last_update_utc` | Когда обновлялись курсы |

## Как работает код
1. `convert()` читает сумму и превращает текст в число через `Number()`.
2. `fetch` запрашивает курсы для валюты «Из».
3. Проверяются `response.ok` и `data.result`.
4. `rate = data.rates[to]`, затем `total = amount * rate`.
5. `toFixed(2)` оставляет два знака после точки.
6. Дата выводится в российском формате через `toLocaleDateString("ru-RU")`.
7. При ошибке выводится «Не удалось получить курс».
8. `convert()` вызывается по отправке формы и один раз при загрузке страницы.

## Как добавить валюту
В `index.html` добавьте строку в **оба** списка (`from` и `to`):

```html
<option value="GBP">GBP - фунт стерлингов</option>
```

JavaScript менять не нужно.

## Ограничения
- Курсы обновляются раз в день.
- Курс справочный и может отличаться от курса банка или обменника.
- Слишком частые запросы сервис может ограничить.

## Идеи для развития
Кнопка «поменять местами», больше валют, график курса.

## Источник данных
