# Генератор шуток

Сайт показывает случайную шутку на английском по нажатию кнопки.

## Возможности
- Категории: любые, про программистов, каламбуры
- Безопасный режим (`safe-mode`)
- Шутки из одной фразы и в формате «вопрос и ответ»
- Кнопка блокируется на время загрузки

## Как запустить
1. Распакуйте проект.
2. Откройте `index.html` в браузере.
3. Нужен интернет. Установка, регистрация и API-ключ не нужны.

## Как пользоваться
Выберите категорию и нажмите «Новая шутка».

## Технологии
HTML, CSS, JavaScript без библиотек и фреймворков.

## Файлы
| Файл | За что отвечает |
|---|---|
| `index.html` | Список категорий, место для шутки, кнопка |
| `style.css` | Жёлтый фон, карточка по центру |
| `script.js` | Получение и вывод шутки |

## API: JokeAPI

`https://v2.jokeapi.dev/joke/Any?safe-mode` (вместо `Any` может быть `Programming` или `Pun`)

| Поле ответа | Значение |
|---|---|
| `error` | `true`, если произошла ошибка |
| `type` | `"single"` или `"twopart"` |
| `joke` | Текст шутки (для `single`) |
| `setup`, `delivery` | Вопрос и ответ (для `twopart`) |

## Как работает код
1. Клик по кнопке вызывает `getJoke()`.
2. Кнопка отключается, показывается «Загрузка...».
3. Из списка берётся категория и отправляется запрос.
4. Проверяются `response.ok` и `data.error`.
5. По `data.type` выбирается, какие поля показать.
6. При ошибке выводится «Не удалось загрузить шутку».
7. Блок `finally` включает кнопку обратно в любом случае.

## Ограничения
- Шутки только на английском.
- Фильтр не даёт стопроцентной гарантии.
- Шутки могут повторяться.

## Идеи для развития
Кнопки «поделиться» и «скопировать», избранное, другие языки.
